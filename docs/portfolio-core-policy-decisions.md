## Approval gates

### Phase 1 authorization

Phase 1 is authorized for the approved import, canonical ledger, account/instrument-scoped `ACB-V1`, split, workbook spin-off, frozen-observation, and conservative instrument-identity policies. This authorization does not authorize database, importer, accounting-engine, API, or UI implementation in the current task.

PC-P0-003, PC-P0-005, and PC-P0-010 remain proposed but do not block non-destructive Phase 1 planning or fixture-driven implementation once their stated behavior is retained.

### Deferred gates

- **Valuation source selection:** PC-P0-011 is approved for v1, but provider/manual selection, cents treatment, FX-after-selection, and provenance must pass private fixture verification before valuation behavior is accepted.
- **Live FX and providers:** PC-P0-008 excludes live providers, and PC-P0-012 approves exact frozen fixture rates only. Live provider selection, fallback windows, and rate substitution rules remain deferred.
- **Performance:** PC-P0-009 approves reproduction of workbook behavior only. PC-P0-013 defers return-of-capital/reinvested-distribution performance classification; that decision blocks Phase 4 performance work, not Phase 1 or the ACB engine.
